# AGENTS.md — правила для всех coding-агентов в этом репо (Codex, Hermes, …)

Этот репо (`pulse`, fomo.spot / terminal.fomo.spot) правят НЕСКОЛЬКО агентов параллельно.
Чтобы не затирать работу друг друга, ОБЯЗАТЕЛЬНО прочитай `COORDINATION.md` и следуй ему.

## Главное (кратко)
1. **Единый источник правды — `origin/master`.** Свою работу коммить и пушь в origin ДО деплоя. Не держи незапушенный серверный код.
2. **Деплой только из origin:** `git fetch && git pull --rebase origin master`, решить конфликты ОБЪЕДИНЕНИЕМ (сохранить обе правки), запушить, затем собрать. **ЗАПРЕЩЕНЫ** tar-распаковка поверх `/opt/fomo` и `git reset --hard` к локальной divergent-копии — они затирают чужие запушенные правки (кнопка возле тикера, фильтр стран, иконки, баннер обновления).
3. **live-билд (`X-Fomo-Build`) должен равняться origin HEAD.** Если нет — кто-то выкатил divergent-копию; пересобери из origin, чтобы вернуть оба набора правок.
4. **Коммить только свои файлы** по явным путям. Чужие staged/dirty-файлы не трогать и не sweeping. Перед правкой чужого файла — сохрани его diff (бэкап WIP).
5. **Одна сборка за раз** на сервере (MemoryMax=10G, MemorySwapMax=0), ждать чужую сборку; не запускать вторую параллельно (swap-фриз).
6. Не возвращать удалённые страны в фильтр (утверждено 8: RU US CN HK JP GB DE IN) — решение пользователя.

Полные детали и очередь коммитов — в `COORDINATION.md`.
